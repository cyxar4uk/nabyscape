# Anyway News · preview 3

Карточка сводки стала компактнее и читабельнее: полный заголовок находится под
фотографией, лишние овальные плашки убраны, в футере остаётся `by Anyway News`.
Нажатие на подпись открывает миниапп, на новость — соответствующую карточку.
Кнопки используют Microsoft Fluent System Icons 20 Regular, MIT.

Заголовки больше не создают всплывающих дублей при наведении. Шапка и футер
остаются на месте, а новости и форма подключения прокручиваются внутри карточки.
На узкой панели дублирующая ссылка «Все новости» скрывается, чтобы сохранить
подпись сервиса. Обновление из кэша сохраняет карточки и загруженные изображения.

Реальные аватарки поддерживаются через отдельный `news-sources.json` в папке
профиля. Каталог из локального просмотра не входит в публичный архив:
в чистом профиле вместо неизвестных аватарок показываются нейтральные круги.
Публичная сводка работает без токенов; чтение всей ленты продолжается в миниаппе.
Новый серверный endpoint ленты подготовлен отдельно и ещё не развёрнут.

## Запуск

Распакуйте portable ZIP для Windows x64 и запустите `NabyScape.exe`.
В Settings → Widgets & tools → Your widgets включите **Anyway News**.
Откройте его в шторке, оставьте адрес `https://news.anyway-community.ru/api`
и нажмите «Подключить». .NET входит в архив, установка runtime не требуется.

Это предварительная сборка форка NabyScape 2.27.0. Встроенное обновление смотрит
upstream; обновления с новостным виджетом скачивайте из релизов этого форка.
Локальные профили, каталог источников и ключи доступа в публикацию не входят.

## Проверка

Оконные проверки новостного модуля выполняются в готовом EXE изолированно:
сохранённый публичный ответ API, реальные обложка и аватарки, ширина 300/526 DIP,
масштаб панели 125%, маленькая высота, открытая форма подключения, светлая тема,
переходы, повторное обновление и границы карточки. Внешние приложения по тестовым
кликам не запускаются — проверяется адрес перехода. Результаты проверки готовой
сборки приложены к релизу.
