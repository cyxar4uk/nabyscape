# Anyway News · preview 4

Аватарки источников теперь загружаются автоматически через публичный API
Anyway News. Достаточно включить виджет и подключить API: отдельный каталог
`news-sources.json` больше не нужен и не читается.

Виджет запрашивает имена и картинки только для источников текущих новостей,
пакетом до 20 ID, и кэширует метаданные на 10 минут. Токены бота, Telegram-сессия
и cookies не используются. Картинки принимаются только с сервера подключённого
API. Ошибка метаданных, отсутствующая аватарка или слишком большой ответ
не скрывают сводку: остаются инициалы либо нейтральные круги.

Сохраняются компактная карточка, Fluent Icons, фиксированный футер,
прокрутка внутри шторки и переходы в миниапп из preview 3.

Распакуйте ZIP для Windows x64 и запустите `NabyScape.exe`.
Settings → Widgets & tools → Your widgets → Anyway News, затем «Подключить».
.NET входит в архив. Встроенное обновление приложения смотрит upstream;
версии с этим виджетом скачивайте из релизов форка.
